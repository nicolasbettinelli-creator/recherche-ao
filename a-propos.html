À propos de Recherche AO

Recherche AO est une application indépendante de consultation rapide des amendes d’ordre.

Elle a été conçue pour permettre une recherche simple par numéro, mot-clé, catégorie, montant ou situation concrète.

Base utilisée

Les données intégrées dans cette version sont basées sur le livret AO 2026 V2 du 29 octobre 2026, sous réserve du contrôle de transcription.

Avertissement important

Cette application est un outil personnel de consultation rapide. Elle ne remplace pas les textes légaux officiels, les directives internes, ni les versions actualisées publiées par les autorités compétentes.

En cas de doute, de modification légale ou d’utilisation formelle, les textes officiels en vigueur font foi.

Fonctionnalités

  • Recherche instantanée des amendes d’ordre
  • Filtres par catégories
  • Mode jour / mode nuit
  • Copie rapide d’une amende
  • Utilisation sur ordinateur et téléphone
  • Consultation depuis un signet du navigateur mobile, sans installation obligatoire
  • Écran de verrouillage de convenance (ne protège pas les fichiers publics GitHub Pages)

Confidentialité

Aucun compte, nom, adresse électronique ou numéro de téléphone n’est demandé. Les recherches sont exécutées localement dans le navigateur. Les préférences d’affichage et l’état du verrouillage sont conservés sur l’appareil. L’hébergeur peut néanmoins enregistrer des données techniques de connexion.
